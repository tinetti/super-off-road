# Super Off Road

An iterative agent-driven development skill inspired by the Ralph Loop.
Uses a lap-based analogy for the loop cycle to track progress on PRD.yml tasks.

## Overview

- Parses a YAML PRD file with tasks and acceptance criteria.
- Tracks task progress and errors within the PRD.yml under a result section.
- Routes task execution models based on effort level.
- Runs iterative laps until all tasks pass acceptance.
- Supports manual validation after automated checks.
